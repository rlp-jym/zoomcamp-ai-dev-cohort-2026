# R2 / S3 bucket and lifecycle policy

## Bucket

Create a Filebase S3-compatible bucket. Set:

- `R2_ENDPOINT_URL`
- `R2_ACCESS_KEY_ID`
- `R2_SECRET_ACCESS_KEY`
- `R2_BUCKET`

## Prefix convention

```
scenarios/<scenario_name>/*.parquet
```

The scenario generator uploads 16 Parquet tables per scenario under this prefix.

## Lifecycle policy (optional)

Old run objects can be expired after N days to control storage costs. A
suggested rule: expire objects under `scenarios/` older than 90 days, except
the `baseline_run/` prefix which must be retained.
